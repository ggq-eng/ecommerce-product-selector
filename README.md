## 📖 使用说明（完整规范）

> 以下为该技能的完整说明，涵盖核心能力、工作流程与关键规则，帮助您全面了解其运作方式。

基于大数据分析的智能选品工具，帮助电商从业者快速发现爆款产品机会。

## 功能特性

- 📊 **市场趋势分析**: 热门品类趋势追踪，新兴品类发现
- 🎯 **竞品分析**: 价格监控、销量估算、评价分析
- 💰 **利润计算**: 自动计算成本、利润空间、ROI
- 🔥 **爆款预测**: 基于历史数据预测爆款潜力
- 📈 **关键词分析**: 搜索热度、竞争度、趋势分析
- 🌍 **多平台支持**: 淘宝、京东、拼多多、抖音、亚马逊

## 使用方式

```bash
# 品类选品
选品 宠物用品 2026年趋势

# 价格区间选品

在抖音平台找美妆爆款

分析关键词 无线鼠标 搜索热度
```

## 选品维度

### 市场维度
- 搜索热度
- 增长趋势
- 季节性因素
- 区域分布

### 竞争维度
- 卖家数量
- 头部集中度
- 价格分布
- 评价数量

### 产品维度
- 质量要求
- 售后难度
- 物流要求
- 合规要求

### 供应链维度
- 货源稳定性
- 成本竞争力
- 起订量要求
- 交货周期
