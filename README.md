# ecommerce-product-selector

> 来源分类：**市场技能** ｜ 导出批次：published

电商平台爆款产品筛选分析 - 基于数据分析的智能选品工具，支持淘宝、京东、拼多多、抖音、亚马逊等平台

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/ecommerce-product-selector__skillhub        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/ecommerce-product-selector__skillhub   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。

- 本技能从本地 WorkBuddy 环境导出，**所有真实密钥已脱敏为占位符**，使用前请配置你自己的 API Key。
